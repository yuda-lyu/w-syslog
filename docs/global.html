Methods

resolveFormatter(opt) → {Object}

Description:

  • 解析transport worker目標formatter.mjs之實體路徑

    依序: (a)本模組上一層為本套件根(驗package.json之name)則取其src/formatter.mjs, 涵蓋src與dist之直接使用; (b)由本模組位置以模組解析取得已安裝之w-syslog/src/formatter.mjs, 涵蓋被下游打包(本模組位置即下游bundle); (c)同上但由cwd解析, 涵蓋bundle被搬離其node_modules樹之情形; (d)皆失敗則拋錯, 訊息含已試位置與指引. 以自身套件名解析在本套件repo內必失敗(package.json無exports不能自我參照), 故(a)須在前

Source:

Example
import resolveFormatter from './src/resolveFormatter.mjs'

let r = resolveFormatter({ fpSelf: 'D:\\my-proj\\node_modules\\w-syslog\\src\\WSyslog.mjs', cwd: process.cwd() })
console.log(r)
// => { fp: 'D:\\my-proj\\node_modules\\w-syslog\\src\\formatter.mjs', by: 'pkgRoot' }
